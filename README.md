# Corewave Project

A modern responsive React website for Corewave, built with Vite and Tailwind CSS.

## Features

- Responsive landing page design
- Hero, About, Services, Portfolio, Testimonials, and Footer sections
- Reusable React components
- Assets organized inside `public/assets`

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript

## Getting Started

Install dependencies:

```
bash
npm install

*Run the development server:

bash
npm run dev

*Build for production:

bash
npm run build

*Preview the production build:

bash
npm run preview

*Project Structure:

src/
  components/
  data/
  App.jsx
  main.jsx
  index.css

public/
  assets/
